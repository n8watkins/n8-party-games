# Nick Saraev's prompts

These four build prompts are by Nick Saraev.
They are the starting point of the n8 Party Games: each game began from one of them (see [Credit](../../README.md#credit)).

| File | Nick's prompt | Became | His video |
| --- | --- | --- | --- |
| [`the-cork-gallery.txt`](the-cork-gallery.txt) | The cork gallery | [Cork & Bell](https://github.com/n8watkins/cork-and-bell), built | [I Threw $1000 at Fable 5.2 to Build The Coolest Demos Possible](https://www.youtube.com/watch?v=wpFw66kKixU) |
| [`the-tile-river.txt`](the-tile-river.txt) | The tile river | Flood, planned | [I Threw $1000 at Fable 5.2 to Build The Coolest Demos Possible](https://www.youtube.com/watch?v=wpFw66kKixU) |
| [`wind-up-derby.txt`](wind-up-derby.txt) | Wind-up derby | Bathtub Regatta, planned | [13 INSANE Things You Can Build w/ Claude Fable 5.2](https://www.youtube.com/watch?v=5mA9Hab09Do) |
| [`the-fox-knight.txt`](the-fox-knight.txt) | The fox knight | Fox Trouble, planned and loosely based on it | [13 INSANE Things You Can Build w/ Claude Fable 5.2](https://www.youtube.com/watch?v=5mA9Hab09Do) |

The text of each file is his, unchanged, taken in November 2026 from the prompt packs he gives away with those two videos.
The packs hold many more prompts than these four.
To get the full packs from Nick himself, go to [Maker Zero](https://www.skool.com/maker-zero/about), his free community on Skool: both videos' descriptions send you there for the prompts.

They are his work.

Nothing in the party site's build or the npm package copies this folder; it is only here in the repository.
